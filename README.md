# Enrico Giuliano

**Pharmacist · Founder & Product Lead of [SOPHIA](https://github.com/EG2025-lab/sophia-pharmacy) · Italy**

I am building SOPHIA to help pharmacists navigate official medicines documentation, Italian pharmaceutical legislation, clinical evidence and guidelines in one professional conversation. Our goals are to reduce information fragmentation and workload, help reduce errors and improve pharmacy service. Their impact still needs to be measured.

FarmAI is available as original custom GPTs and private Business plugins derived from their copies. SOPHIA is a separate application under development, with its own restricted beta. The public repository shares documentation, evaluation proposals and collaboration opportunities; application source code is not published there.

The deployed professional beta is **0.7.110-beta**, restricted to owner-approved users; payments and answer charging remain inactive. 110 fixes common output-privacy composition, clinical web-recovery focus, no-progress search variants, manual error readback and source-title issues. There is no fixed global model-call ceiling. Source admission, privacy, bindings and full semantic review remain required. **1,749 offline checks and56 interface checks** passed; no live110 model question was sent. Six real109 repeats produced **two useful scoped answers, three partial answers and one failed request**.44 internal model calls, a conservative2.283USD estimate, not invoice. Latency ranged about34–128seconds. Structured retrieval and independent web were both attempted where relevant; clinical and legal completeness still had gaps. This does not establish an overall efficiency improvement. [Current status](https://github.com/EG2025-lab/sophia-pharmacy/blob/main/docs/STATUS.md).
